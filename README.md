# OrcheCall: A Workspace for Flowchart-Guided Voice Agents

OrcheCall is a web workspace for configuring, testing, and reviewing customer service voice agents. It connects editable Service Flowcharts with browser-based voice testing, telephone operations, and transcript review, helping operators compare an intended procedure with what the agent actually did.

This repository accompanies our demo submission to The Web Conference 2027 (WWW '27).

## Demo walkthrough

1. **Inspect a Service Flowchart.** Open the Mandatory Provident Fund (MPF) withdrawal agent and review its service steps and decision conditions.
2. **Talk to the agent.** Ask, “Can I withdraw my MPF in one lump sum?” Observe which information the agent requests before explaining the application process.
3. **Revise a requirement.** Change a flowchart instruction, start a new voice session, and ask the same question again.
4. **Compare the transcripts.** Check how the revised requirement affects the agent's follow-up questions.
5. **Review a call.** Explore a completed call's transcript and available call details in the operator workspace.

The video shows this sequence for visitors who cannot access the live service or use a microphone.

## What OrcheCall provides

- An editable Service Flowchart for specifying service steps, decision conditions, and exception paths.
- Browser-based voice testing with a live transcript.
- Inbound and outbound telephone operations.
- Call records for reviewing agent behavior and refining the procedure.

## Access

Use a desktop browser and allow microphone access to try the voice interaction. Some operator features may require a demo account.
